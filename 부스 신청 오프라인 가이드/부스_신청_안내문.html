부스 신청 절차 안내
Booth Application Guide

홈페이지 부스 신청부터 결제까지 한눈에 보는 단계별 가이드

일시
2026년 6월 1일(월) – 6월 2일(화)
장소
스위스 그랜드 호텔 (Swiss Grand Hotel, Seoul)
부스 가격
₩2,200,000 (부가세 포함) · 2m × 2m × 2.5m
신청 페이지
https://www.nc26-bnikorea.com/ticket.html

전체 흐름 (총 7단계)

  1. 티켓 페이지의 "부스 전시" 카드에서 [부스 선택하기] 버튼 클릭
  2. 부스 배치도 모달에서 Zone A · Zone B 자리 확인
  3. 원하는 부스(주황색) 클릭 → 하단 [신청서 작성 · Apply] 버튼 클릭
  4. 참가 업체 / 신청자 정보 입력
  5. 회사 로고·홍보자료 첨부 + F&B 영업신고(필수) 항목 확인
  6. 부스 사이즈 확인 후 [부스 신청 제출] 클릭
  7. 결제 페이지 자동 이동 → 가상계좌 / 신용카드 / 카카오페이 결제

NC 26부스 신청 안내
STEP 1

티켓 페이지에서 [부스 선택하기] 클릭

홈페이지 → 티켓 페이지 하단의 "부스 전시" 카드에서 신청을 시작합니다.

📌 화면 안내
  • 부스 전시 카드에 표시된 가격 ₩2,200,000 (부가세 포함) 확인
  • 포함 사항: 상단 간판 디자인·설치 / 프로그램 광고 게재 / 행사 당일 새벽 2시부터 셋업 가능
  • 오른쪽 하단 주황색 [부스 선택하기] 버튼을 클릭하면 부스 배치도 모달이 열립니다.
💡 결제 수단은 가상계좌 / 신용카드 / 카카오페이 3가지 모두 지원합니다.
STEP 1 / 7nc26-bnikorea.com
NC 26부스 신청 안내
STEP 2

부스 배치도 확인 (Zone A · Zone B)

스위스 그랜드 호텔 행사장 도면 위에서 실제 부스 위치와 판매 상태를 한눈에 확인합니다.

📌 부스 색상 구분
  • 주황 선택 가능 (Available)
  • 빨강 내가 선택 중인 부스 (Selected)
  • 회색 판매 완료 (Sold) — 선택 불가
  • 흰색 테두리 BNI 부스 (BNI Booth)
💡 Zone A는 메인 게이트 앞 직선 라인, Zone B는 행사장 우측 곡선 라인(Foyer)입니다.
STEP 2 / 7nc26-bnikorea.com
NC 26부스 신청 안내
STEP 3

원하는 부스 선택 → [신청서 작성 · Apply]

주황색(선택 가능) 부스를 클릭하면 빨간색으로 바뀌고, 하단 바에 선택 정보가 표시됩니다.

📌 화면 안내
  • 선택한 부스 번호(예: A03)와 Zone, 가격(₩2,200,000)이 화면 하단에 표시됩니다.
  • 다른 부스로 변경하고 싶으면 다른 주황색 부스를 다시 클릭하면 됩니다.
  • 부스를 확정했다면 우측 하단 빨간색 [→ 신청서 작성 · Apply] 버튼을 클릭합니다.
⚠️ "Sold"로 표시된 회색 부스는 이미 판매 완료되어 선택할 수 없습니다.
STEP 3 / 7nc26-bnikorea.com
NC 26부스 신청 안내
STEP 4

참가 업체 · 신청자 정보 입력

선택한 부스 번호가 자동으로 표시된 상태에서 회사 정보와 신청자 정보를 작성합니다.

📌 입력 항목
  • 참가 업체: 회사명 · 대표자명 · 주소(우편번호 포함) · 대표전화 · 팩스 · 홈페이지 · E-Mail
  • 신청자 정보: 신청자명 · 챕터(BNI 멤버 시) · 전화(휴대폰) · 이메일 · 사업자등록번호
  • 모든 * 표시 항목은 필수 입력입니다.
💡 부스 번호는 화면 상단 빨간 박스에 자동 표시됩니다. 변경이 필요하면 우측 [변경 · Change] 클릭.
STEP 4 / 7nc26-bnikorea.com
NC 26부스 신청 안내
STEP 5

파일 첨부 · F&B 영업신고 항목

회사 로고/홍보자료를 업로드하고, 식음료 부스 운영 시 필수 영업신고 안내를 확인합니다.

📌 첨부 · 셋업 안내
  • 홍보자료 업로드: AI / PNG / JPG / PDF · 파일당 최대 5MB
  • 5MB 초과 시 admin@bni-korea.com으로 별도 이메일 송부
  • 부스 셋팅 시간: 행사 당일 새벽 2시부터 가능 (이전 요청 시 개별 협의)
  • F&B 부스 영업신고(필수): 일반 음식물 신고가 되어있는 업체만 가능 (추가 케이터 조리 가능), 장부24 홈페이지 "행사장 영업신고" 진행 — 개인 사업자: 영업신고증 / 법인 사업자: 영업신고증 + 법인 등기부등본 + 인감증명서 첨부
  • 현장에서 식·음료 시식 불가, 판매로 판매만 가능
STEP 5 / 7nc26-bnikorea.com
NC 26부스 신청 안내
STEP 6

부스 사이즈 확인 → [부스 신청 제출]

제공되는 부스 규격을 시각적으로 확인하고 신청을 최종 제출합니다.

📌 부스 사양
  • 사이즈: 2m(가로) × 2m(세로) × 2.5m(높이)
  • 상단 간판 디자인·설치 지원 / 프로그램 광고 게재
  • 아래 빨간색 [부스 신청 제출] 버튼 클릭 시, 신청 정보가 저장되고 자동으로 결제 페이지로 이동합니다.
💡 신청 후 결제 안내는 신청자 이메일로도 자동 발송됩니다.
STEP 6 / 7nc26-bnikorea.com
NC 26부스 신청 안내
STEP 7

결제 진행 (NC 26 결제 페이지)

자동으로 이동된 결제 페이지에서 신청자 정보를 입력하고 결제를 완료합니다.

📌 결제 안내
  • 상품 유형: Exhibition Booth (자동 선택됨)
  • 입력 항목: 이름 · 이메일 · 연락처 · 지역 등
  • 결제 수단: 가상계좌 / 신용카드 / 카카오페이 (3가지 중 선택)
  • 결제 완료 후 주최측 확인 메일이 자동 발송되며, 부스 위치가 최종 확정됩니다.
📞 결제 관련 문의: BNI Korea (admin@bni-korea.com) · 카카오톡 채널 @BNI Korea
